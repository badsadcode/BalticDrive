# People

`Bandits/bandit_1.glb` … `bandit_8.glb`: the bandits' bodies (D129). Generated by **BadCharacters**
(github.com/badsadcode/BadCharacters, commit dfdfca7, with BadGun at b8b0408), the studio's own procedural character
generator by Tom (Bad Ideas Works): the studio's own work, part of Baltic Drive. Brick style (Tom's pick), five
from the *survivor* theme and three *wasteland raiders*, no weapons; each `.badchar.json` is its full recipe.

Made by `tools/people/export_bandits.ts` (same seeds, same people, byte for byte). Each GLB holds one skinned mesh
(about 1.1k–1.5k triangles), the 25-bone Unity-named humanoid skeleton, sockets, and 87 baked clips (Walk, Run,
Sprint, Crouch, CrouchWalk, Crawl, Talk, Eat, SitGround…). Metres, +Y up, facing +Z, feet on y = 0.
Godot extracts each one's textures (face, patterned clothes) as PNGs beside it on import.
