# Petrol can

`petrol_can.glb`: a jerrycan made by Tom (Bad Ideas Works) with Meshy AI on his commercial subscription, 21 Nov 2026,
for Baltic Drive. One mesh (about 1,000 triangles), one texture (`petrol_can_Image_0.png`, extracted by Godot's
import). Modelled 0.95 m tall; the game scales it ×0.37 to a 5-litre can (D109).
