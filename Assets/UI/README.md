# Baltic Drive UI art (v1)

Interface pieces made by Tom (Bad Ideas Works) with Codex image generation for this game, 21 November 2026, from the
brief in `docs/UI_ASSETS_BRIEF.md`. Tom's own art: part of the game and this repository (not third-party assets).
Drawn at 2× size; `UI/Skin.cs` shrinks them to screen size and builds nine-slice styles from `manifest.json`.

## Icons and the notebook (v1)

`icons/`: item icons (one per item id, 78), category and freshness badges, and the crafting notebook's art (a page,
sticker tabs, pencil marks, a coffee ring), made by Tom with Codex on 22 November 2026 from `docs/ICON_ASSETS_BRIEF.md`
(D117/D118). Tom's own art, like the rest. Only the pieces the game uses are here; the rest of the delivery stays in
`data/inbox`.
