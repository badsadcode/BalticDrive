# Guns

The game's guns (D130), generated by **BadGun** (github.com/badsadcode/BadGun, commit b8b0408, as BadCharacters'
submodule), the studio's own procedural weapon generator by Tom (Bad Ideas Works): the studio's own work, part of
Baltic Drive. Picked by Tom from a lineup of 18 (WW1, WW2 and modern; he wants WW2, WW1, maybe modern):

| File | Recipe | In the game |
|---|---|---|
| `rifle.glb` | rifle, ww2, seed 3, bolt action, internal magazine | slot `mosin`: the bolt-action rifle |
| `smg.glb` | smg, ww2, seed 1 (drum) | slot `ak`: the submachine gun |
| `pistol.glb` | pistol, ww2, seed 2 | slot `pistol` (yours), and one of three bandit looks |
| `pistol_b.glb` | pistol, ww2, seed 1 | a bandit's pistol |
| `pistol_c.glb` | pistol, ww1, seed 1 (toggle lock; no Reload clip) | a bandit's pistol |

Made by `tools/guns/export_guns.ts` (same recipes, same guns). Each `<id>.json` is BadGun's manifest. In each GLB:
the trigger grip at the origin, +Z to the muzzle, +Y up, metres; `SOCKET_*` nodes (grip, support hand, ADS, muzzle,
eject, magazine…); moving parts by name (Slide, Magazine, BoltHandle, Trigger…) and the clips Fire, Reload, Cycle.
The game reads all of these from the file (`WeaponDef.BadGun`).
